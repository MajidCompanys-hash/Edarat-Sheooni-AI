# إدارة شؤوني — نموذج مالي شخصي

نسخة أولية مستقلة باللغة العربية واتجاه RTL، بعملة الريال العُماني (ثلاث خانات عشرية). تحفظ البيانات في `localStorage` داخل المتصفح.

## التشغيل

- افتح `index.html` لمعاينة الوظائف الأساسية. بعض المتصفحات تقيد تخزين Service Worker عند فتح الملف مباشرة.
- لتجربة PWA والعمل دون اتصال، ارفع محتويات المجلد إلى استضافة HTTPS (مثل GitHub Pages)، ثم افتح الرابط مرة واحدة.
- على iPhone: افتح الرابط في Safari ثم «مشاركة» ← «إضافة إلى الشاشة الرئيسية».

## الوظائف الموجودة

- لوحة ملخص، أرصدة الحسابات، دخل ومصروفات مع فئات وتواريخ.
- متابعة ديون عليك ومبالغ مستحقة لك، وفواتير، وحدود ميزانيات شهرية.
- حفظ محلي تلقائي، مظهر داكن، واجهة متجاوبة وتهيئة Service Worker.
- تصدير واستيراد JSON خاص بهذا النموذج.

## حدود النسخة

- لا تستورد هذه النسخة بيانات تطبيق «إدارة شؤوني» القديم. ملف النسخة الاحتياطية غير متوفر هنا، لذا يلزم فحصه قبل بناء محول آمن.
- لا تتصل بخدمة ذكاء اصطناعي ولا تقدم توصية مالية مخصصة؛ التحليلات الحالية تلخيصية فقط.
- البيانات في التخزين المحلي غير مشفرة على مستوى التطبيق. لا تعتمد على هذا النموذج وحده لحفظ سجلات مالية مهمة؛ احتفظ بتصدير JSON في مكان آمن.
- هذه أداة أولية؛ تحقّق من الأرصدة والعمليات قبل استخدامها كسجل مالي فعلي.
